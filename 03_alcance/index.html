3. Definición del alcance

3.1. Alcance funcional

El proyecto comprenderá el diseño e implementación de una infraestructura virtualizada para el Hotel Vértigo 1958 y una plataforma web destinada a la gestión de reservas.

Las principales funcionalidades serán:

  • Gestión de clientes.
  • Gestión de habitaciones.
  • Gestión de reservas.
  • Consulta de disponibilidad.
  • Registro y consulta de información desde la plataforma web.
  • Gestión administrativa de la información.
  • Almacenamiento centralizado de los datos.
  • Configuración de los servicios de red necesarios.
  • Realización de copias de seguridad de la información.
  • Aplicación de medidas básicas de seguridad.

3.2. Alcance técnico

La solución se desarrollará mediante una infraestructura virtualizada basada en Docker.

Se configurarán los servicios necesarios para ejecutar la plataforma web y la base de datos, además de los servicios de red, seguridad y copias de seguridad necesarios para el funcionamiento del sistema.

La infraestructura se diseñará de forma modular para facilitar su configuración, mantenimiento y ampliación.

3.3. Alcance temporal

El proyecto se desarrollará durante el periodo establecido para el Proyecto Intermodular de ASIR.

Las principales fases serán:

  1. Análisis y planificación.
  2. Diseño de la infraestructura.
  3. Configuración del entorno virtualizado.
  4. Implementación de los servicios.
  5. Desarrollo y configuración de la plataforma web.
  6. Configuración de la base de datos.
  7. Aplicación de medidas de seguridad.
  8. Configuración de copias de seguridad.
  9. Pruebas y verificación.
  10. Documentación final.

3.4. Recursos necesarios

Para desarrollar el proyecto serán necesarios los siguientes recursos:

  • Un equipo informático para el desarrollo y administración del proyecto.
  • Docker para la ejecución de los servicios mediante contenedores.
  • Sistema operativo Linux para el entorno de trabajo.
  • Servidor web.
  • Sistema gestor de bases de datos.
  • Herramientas de desarrollo web.
  • Git y GitHub para el control de versiones y documentación.
  • GitHub Pages para publicar la documentación del proyecto.

3.5. Elementos fuera del alcance

El proyecto no contempla inicialmente:

  • La integración con sistemas externos de reservas.
  • El desarrollo de una aplicación móvil.
  • La gestión de pagos online reales.
  • La conexión con sistemas reales de facturación.
  • La implantación de la infraestructura en los servidores físicos de un hotel real.
