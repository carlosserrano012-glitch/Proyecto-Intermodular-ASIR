1. Introducción

1.1. Título del reto

Diseño e implementación de una infraestructura virtualizada y plataforma web para la gestión de reservas del Hotel Vértigo 1958.

1.2. Contexto

El Hotel Vértigo 1958 es un pequeño establecimiento del sector hotelero que ofrece alojamiento y diferentes servicios a sus clientes.

La gestión del establecimiento cuenta con personal administrativo encargado de gestionar las reservas y atender las solicitudes de los clientes. Actualmente, gran parte de estas tareas se realizan de forma manual.

Las reservas se realizan principalmente por teléfono y posteriormente el personal registra la información en hojas de cálculo y documentos de texto.

El hotel busca modernizar su sistema de gestión y disponer de una infraestructura tecnológica que permita centralizar la información y facilitar la gestión de las reservas.

Esta situación constituye el punto de partida para el desarrollo del proyecto.

1.3. Problemática o necesidad

Actualmente, el Hotel Vértigo 1958 depende en gran medida de procedimientos manuales para gestionar la información relacionada con sus reservas.

Las reservas se realizan principalmente mediante llamadas telefónicas y posteriormente la información se registra en diferentes documentos de Word y hojas de cálculo de Excel. Esto provoca que los datos puedan encontrarse repartidos entre distintos archivos.

Esta situación dificulta la consulta y organización de la información y aumenta el riesgo de introducir datos incorrectos o duplicados.

Además, el hotel no dispone actualmente de un sistema centralizado para gestionar la información de clientes, habitaciones y reservas, ni de una alternativa online para que los clientes puedan consultar las habitaciones y solicitar una reserva.

Por tanto, existe la necesidad de mejorar la forma en la que se organiza, consulta y gestiona esta información, reduciendo la dependencia de procedimientos manuales.

1.4. Objetivos

Objetivo general

Implementar una infraestructura virtualizada que permita centralizar la gestión de reservas del Hotel Vértigo 1958.

Objetivos específicos

  1. Diseñar una infraestructura informática adecuada.
  2. Crear un entorno virtualizado mediante Docker para los diferentes servicios.
  3. Instalar y configurar un sistema Linux para los servicios.
  4. Implementar un servidor web para alojar la web del hotel.
  5. Crear una base de datos para almacenar la información de clientes, habitaciones y reservas.
  6. Crear una página web para el hotel.
  7. Permitir que los clientes puedan consultar las habitaciones y realizar solicitudes de reserva.
  8. Crear una zona de administración para gestionar la información.
  9. Configurar los servicios de red necesarios para el funcionamiento de la infraestructura.
  10. Implementar medidas básicas de seguridad para proteger los servicios y la información almacenada.
  11. Configurar un sistema de copias de seguridad de la base de datos y de la información importante.
  12. Automatizar determinadas tareas de mantenimiento mediante scripts.
  13. Documentar la infraestructura, configuración y procedimientos.
  14. Facilitar la futura ampliación del sistema.

1.5. Interesados

Los principales interesados del proyecto son las personas que participan en la gestión del hotel, utilizan el sistema o tienen relación con su desarrollo y mantenimiento.
